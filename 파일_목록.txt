## 📊 파일 설명

### 핵심 코드 (backend/)

**main.py** (410줄)
- FastAPI 서버
- REST API 엔드포인트
- 파일 업로드/다운로드
- 템플릿 관리

**hwp_converter.py** (크기 큼)
- COM API 기반 변환 로직
- 한컴오피스 자동화
- 텍스트 서식 처리
- 표 변환 (셀 병합 실패)

**requirements.txt**
- fastapi
- uvicorn
- python-docx
- pywin32
- lxml

### 실행 스크립트

**start.bat**
- 통합 메뉴 시스템
- 서버 시작/종료
- 브라우저 자동 열기

**start_server.bat**
- 빠른 서버 시작
- 백그라운드 실행

**stop_server.bat**
- 실행 중인 서버 종료
- 프로세스 정리

**install.bat**
- Python 의존성 설치
- pip install -r requirements.txt

### 테스트 스크립트

**test_conversion.py** ✅ 성공
- 텍스트 색상 테스트
- 문단 정렬 테스트
- 들여쓰기/내어쓰기 테스트
- 결과: test_formatting.hwp (완벽)

**test_simple_table.py** ✅ 성공
- 간단한 3x3 표
- 셀 병합 없음
- 결과: test_simple_table.hwp (정상)

**test_table_conversion.py** ❌ 실패
- 복잡한 표 (셀 병합)
- 결과: 표 레이아웃 완전 깨짐

**create_complex_table.py**
- 5x5 표 생성
- 셀 병합 (가로, 세로, 블록)
- 셀 배경색
- 폰트 크기 및 색상

### 프론트엔드 (frontend/)

**index.html**
- 다크 테마 UI
- 파일 업로드
- 드래그 앤 드롭
- 변환 진행 표시

**style.css**
- 다크 테마 스타일
- 반응형 디자인
- 애니메이션

**app.js**
- REST API 통신
- 파일 업로드 로직
- 다운로드 처리

### 테스트 파일

**성공한 변환**
- test_formatting.docx → test_formatting.hwp
  - 빨강, 녹색, 파랑, 보라, 주황 텍스트
  - 좌/중/우/양쪽 정렬
  - 들여쓰기, 내어쓰기, 복합 들여쓰기

- test_simple_table.docx → test_simple_table.hwp
  - 3x3 간단한 표
  - 텍스트만

**실패한 변환**
- test_complex_table.docx
  - 5칸 가로 병합 ❌
  - 2칸 세로 병합 ❌
  - 2x2 블록 병합 ❌
  - 셀 배경색 ❌
